# Frontend-only rules

- This repository is frontend-only. Do not create backend/, FastAPI, Python, or server files here.
- Use React + Vite.
- Keep the UI mock-data first until the API contract is agreed.
- The global animated background is atmospheric only. Never place repository nodes, file names, or architecture edges in it.
- Repository topology belongs in the dedicated Architecture Graph report view.
- Preserve the investigation flow and existing routes unless the task explicitly changes them.
- Prefer small reusable components under src/components.
- Do not introduce gradients/neon everywhere; keep the dark engineering/forensic aesthetic restrained.
